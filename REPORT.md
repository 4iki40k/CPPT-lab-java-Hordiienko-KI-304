# Звіт до лабораторної роботи №1

> Робоча чернетка. Заплановані можливості не є підтвердженими результатами.

## 1. Тема, номер і варіант

- Тема: розгортання Java-проєкту та базова обробка даних.
- Лабораторна робота: №1.
- Варіант: 9 — комунальні показники.
- Операційна система: Linux.
- Репозиторій: https://github.com/4iki40k/CPPT-labs-java

## 2. Мета роботи

Створити консольну програму для обробки комунальних показників та налаштувати
відтворювану збірку, тестування, статичний аналіз і пакування на трьох ОС.
Наразі перевірено базовий цикл роботи з JDK та компіляцію через Maven Wrapper.

## 3. Постановка задачі

Вхід: UTF-8, один запис на рядок, поля `meter;date;value;tariff`.
Обов'язкові текстові поля непорожні; числові поля невід'ємні.
Дата зберігається як текст YYYY-MM-DD, календарний розбір не вимагається.

Показники:

1. Кількість коректних записів.
2. Сумарне споживання: сума `value`.
3. Загальна вартість: сума `value × tariff`.
4. Найбільше споживання: максимум `value`.

Хибні рядки потрібно пропускати з повідомленням номера й причини.
Звіт має виводитися в консоль і файл.

## 4. Структура програми

Наразі `src/main/java/ua/lpnu/kzp/Hello.java` містить навчальну програму
перевірки JDK у пакеті `ua.lpnu.kzp`.
Предметна програма ще не реалізована. Структуру її методів і пакетів буде
описано після погодження та реалізації.

## 5. Інфраструктура

Перевірено навчальний запуск через `javac`, `java` та `jar` із JDK 21.
На машині також установлена Java 11, яка була типовою під час початкової
перевірки; для роботи обрано встановлений JDK 21.

Додано базові правила Git, завершень рядків, кодування та відступів.
Налаштовано `pom.xml` із координатами `ua.lpnu.kzp:lab-java:1.0.0`,
цільовою Java 21, UTF-8 і Compiler Plugin 3.13.0.
Глобальний Maven 3.10.0 використано для початкової перевірки та генерації
Wrapper 3.3.4 типу `only-script`; Wrapper запускає Maven 3.9.11.
Додано початковий CI: матриця Ubuntu, Windows і macOS, JDK 21 Temurin,
кеш Maven та `clean compile` через відповідний для ОС скрипт Wrapper.
Workflow запускається на push і pull_request з дозволом `contents: read`.
JUnit 5, SpotBugs і Shade ще не налаштовано.

## 7. Приклади роботи

Студент виконав навчальний цикл:

```bash
javac -encoding UTF-8 Hello.java
java Hello
jar --create --file hello.jar --main-class Hello Hello.class
java -jar hello.jar
```

Повідомлений студентом результат: обидва способи запуску працюють.
Вивід програми: `Привіт, Java!`.
Приклади обробки CSV та файлового звіту буде додано після реалізації.

## 8. Тестування

Виконано ручну перевірку навчального класу та JAR.
Після налаштування Maven асистент виконав із JDK 21:

- `mvn validate` — `BUILD SUCCESS`.
- `./mvnw --version` — Maven 3.9.11, Java 21.
- `./mvnw -B -ntp clean compile` — `BUILD SUCCESS`, скомпільовано один файл.
- `java -cp target/classes ua.lpnu.kzp.Hello` — `Привіт, Java!`.

`-B` вмикає пакетний режим, `-ntp` прибирає індикатори завантажень.
Автоматизованих тестів поки немає.

Початковий [запуск GitHub Actions №40262369303](https://github.com/4iki40k/CPPT-labs-java/actions/runs/40262369303)
для коміту `267c7fd` завершився успішно на Ubuntu, Windows і macOS.
На кожній ОС виконано `clean compile` через Wrapper із JDK 21 Temurin.
Цей запуск не перевіряє тести, виконання програми чи пакування JAR.
