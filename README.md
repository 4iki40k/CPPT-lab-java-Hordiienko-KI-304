# Лабораторні роботи з Java

Репозиторій: https://github.com/4iki40k/CPPT-labs-java

Java-частина курсу «Кросплатформні засоби програмування». Python-частина
ведеться окремо.

## Поточний стан

Виконано навчальну перевірку JDK: компіляцію, запуск класу та виконуваного JAR.
Maven, тести й GitHub Actions ще не налаштовано. Предметну програму ще не реалізовано.

## Лабораторна №1 — варіант 9

Заплановано консольну програму для комунальних показників. Вхід — файл UTF-8
без заголовка, один запис на рядок:

```text
meter;date;value;tariff
```

Приклад запису:

```text
Електроенергія;2026-09-01;120.5;4.32
```

Програма має перевіряти записи, повідомляти номер і причину пропуску хибного
рядка та обчислювати кількість коректних записів, сумарне споживання,
загальну вартість і найбільше споживання. Один текст звіту виводитиметься
в консоль і файл. Заплановані параметри: `--help`, `--input`, `--output`, `--version`.

## Поточний навчальний запуск

Потрібен JDK 21. Із кореня репозиторію:

```bash
javac -encoding UTF-8 Hello.java
java Hello
jar --create --file hello.jar --main-class Hello Hello.class
java -jar hello.jar
```

Очікуваний вивід обох запусків:

```text
Привіт, Java!
```

`Hello.class` і `hello.jar` генеруються локально й не входять до репозиторію.
Команди Maven та запуск предметної програми буде додано після їх перевірки.

## Організація роботи

- `main` — прийняті й перевірені зміни.
- Робота над лабораторними виконується в окремих гілках із Pull Request у `main`.
- Завдання й дефекти фіксуються через GitHub Issues.
- `REPORT.md` містить звіт і облік допомоги ШІ; правила ролей — у `ai/`.

Це погоджений порядок роботи; Issues, робочі гілки та PR ще потрібно створити.
